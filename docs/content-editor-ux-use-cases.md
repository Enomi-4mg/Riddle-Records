# Content Editor の UX ユースケース

現行経路は App → ContentList / CmsEditor / AboutEditor / MediaLibrary。以下を実際の操作と自動テストで確認する。

## 一覧と画面移動

- 種別・公開状態・検索条件はURLへ保存され、記事から戻る、reload、ブラウザの戻る／進むでも復元する。
- 一覧の下部から記事を開くとタイトル付近から表示する。新規作成、About、メディアも先頭へ移動する。
- 一覧へ戻ると同じ条件のスクロール位置を復元する。履歴移動は各履歴の位置を使う。フィルター変更だけでは先頭へ戻さない。
- Journal の説明が空ならOG説明を一覧・検索にも使う。Aboutは記事一覧・新規作成・削除の対象外。

## 編集・保存・公開

- 本文、タイトル、説明、タグ、記事設定、メディア情報は編集ごとにブラウザの保留変更へ自動保存する。編集せず開いただけでは保留変更を作らない。
- reload後も保留内容を復元する。「入力を確認」は検査の操作であり、追加保存の境界にしない。容量不足はエラー表示する。
- 「公開に設定」「非公開に設定」で次の反映時の状態を変更する。初回公開の公開日は日本時間の当日、手入力日は優先、再編集・再公開では既存日付を維持する。
- 「保留変更をサイトに反映」で全件の保存・削除・メディア情報を確認してから反映する。別タブで内容が変わったら再確認する。
- ステータスは継続状態、通知は一時的な操作結果として別に表示する。詳細からrevision・Workflow・再確認等へ到達できる。
- 別タブ・デプロイ中は編集を止める。通信失敗やtimeoutでは追跡を維持し、再確認・reload復帰できる。

## 種別ごとの編集

- Journal：リード文とOG説明を区別し、OGだけの既存記事も保存時に保持する。記事設定で種別・slug・公開日・サムネイル・OG情報を編集する。「Journalの初期設定」はJournal画面だけに出す。
- Songs：YouTube URL / ID、複数行クレジット・歌詞を記事キャンバスで編集する。
- Gallery：作品画像、代替テキスト、タグ、slug、詳細記事の有無を編集する。既存関連記事は本文として保持する。
- Projects：状態・ヒーロー画像・本文・リンク・タグを編集する。既存featuresは本文の「主な機能」へ移す既定の互換変換で保持する。
- About：固定プロフィールとFeatured Worksを編集し、作品順序・非公開／削除参照・重複を検査する。
- 本文：＋ / スラッシュメニュー、URL貼り付け、画像ピッカー、リンクカード・YouTube・X・Spotifyを使う。既存iframe等はHTML互換ブロックで保持する。

## サイト相当プレビュー

- CmsEditorの「サイトでの見え方」から現在の入力を確認する。公開・保存操作は不要で、日付未設定の下書きも表示できる。
- 公開サイトのmain / animations / gallery / journal / embeds CSS、HeaderのCSS、Kiwi Maru 400 / 500、本文幅と種別別レイアウトを使う。
- 通常幅と375px幅を切り替える。本文、リード、画像、クレジット、歌詞、状態、リンク、リンクカードとサービス埋め込みを確認する。
- iframe内にスタイルを隔離する。sandboxでscript・親画面アクセス等を許可しない。埋め込みの再生、Xの動的表示、数式・syntax highlight・Lightbox・メニュー等の動作は公開後の確認対象として画面にも明示する。
- Escape / 「編集に戻る」で閉じ、起動ボタンへfocusを戻す。

## モバイルとキーボード

- 320px / 375px幅で固定上部バーは戻る・状態・サイト反映だけを表示し、入力を確認・公開設定・記事設定・プレビュー・Journal初期設定は本文側へ置く。
- 共通Popoverはviewport内へ収まり、長いメニューは内部scrollする。外側click、Escape、trigger再clickで閉じる。
- Blockの追加・上下移動・drag/drop、設定欄、確認dialogをキーボードでも操作できる。

## 削除・取消・競合

- 記事削除はタイトル・kind・pathの確認後に保留する。新規下書きはファイル削除ではなくブラウザ下書きの破棄と説明する。
- 確認を取り消せば編集を維持する。保留一覧から記事保存・削除・メディア情報を個別に取り消せる。
- 未反映保存の取消はGitHub版へ戻り、新規下書きの取消はブラウザから除く。GitHub反映済み／デプロイ中は取消を拒否する。
- revision競合は再読込・破棄・対象別強制反映から選び、無関係な内容を上書きしない。

## 旧コンポーネントの判断

| 旧コンポーネント | 判断と現行の代替 |
| --- | --- |
| EditorScreen | 削除。CmsEditorが本文・配置先・公開操作を担当する |
| DraftList | 削除。ContentListが一覧・新規作成を担当する |
| SettingsDrawer | 削除。CmsEditorの記事設定を使用する |
| ReviewPane | 削除。入力を確認・公開チェック・開発者情報へ役割を統合する |
| ImageCardTool | 削除。画像ピッカー／埋め込みを使用し、既存カードHTMLは互換ブロックで保持する。旧HTML生成・Galleryコード生成UIは現行機能にしない |
| FullPreviewScreen | 削除。現行ContentDocumentを使うSitePreviewDialogへ機能を移植する |

上記画面へのimport・テストは残さない。旧Draftのデータ変換helperは旧ツール／互換テストで使用するため別途保持し、現行CMSのcoverageから除外する。
